Configurações rápidas

Entre com uma chave de acesso do GitHub para editar o site. As mudanças entram no ar em cerca de 1 minuto.

Como criar a chave (uma vez só):
  1. Abra github.com/settings/personal-access-tokens/new
  2. Em Repository access, escolha Only select repositories → syntra-site
  3. Em Permissions → Repository, coloque Contents: Read and write
  4. Defina uma validade, gere a chave e cole aqui

Use "Lembrar" só em computador seu. A chave fica apenas neste navegador e vale só para este repositório.
